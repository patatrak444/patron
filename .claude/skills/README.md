# Skill del progetto

Quattro skill da [Three.js Game Skills](https://github.com/majidmanzarpour/threejs-game-skills)
di Majid Manzarpour (licenza MIT, vedi `LICENSE-threejs-game-skills`), commit `8286774b22a2566bf894dbc825825c16921866af`.

- `threejs-gameplay-systems`: meccaniche e game feel (solo `SKILL.md` e `references/`; il progetto di partenza è escluso).
- `threejs-aaa-graphics-builder`: scheda di valutazione visiva, luci, materiali, budget.
- `threejs-qa-release`: screenshot e controlli prima della consegna.
- `threejs-debug-profiler`: schermate nere, errori, prestazioni.

Due skill scritte per PATRÓN:

- `arcade-idle`: l'enciclopedia del genere (cosa fanno i giochi di successo).
- `ux-ui-arcade-idle`: il progettista di esperienza (regole UX1–UX12 e 19 controlli per screenshot e partite), costruita sull'enciclopedia, su una ricerca dedicata e sul video completo di Pizza Ready.

Le altre skill del pacchetto (director, generatori di immagini, modelli 3D e audio) non sono installate:
richiedono chiavi a pagamento o impongono una propria struttura di progetto.

Regola: **`docs/GDD.md` e `CLAUDE.md` vincono sempre sulle skill.** Le skill citano a volte
un progetto di partenza, uno scaffold o la skill director: qui non esistono, si usa l'architettura
della sezione 14 del GDD e lo script `npm run shot` per gli screenshot.
