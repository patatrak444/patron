# Sintesi: le regole del genere

Compilata nella fase 4. Ogni regola ha un enunciato, in quanti giochi del catalogo compare (es. 10/11), l'intervallo numerico se misurabile e il file da cui viene. La soglia per entrare è metà del catalogo: almeno 6 giochi su 11. Fanno eccezione le regole numeriche misurate solo su alcuni giochi, che lo dicono esplicitamente.

| File | Cosa contiene |
| --- | --- |
| `regole-forma.md` | 21 regole di forma (RF1–RF21) e le osservazioni sotto soglia |
| `regole-contenuto.md` | 21 regole di contenuto (RC1–RC21), i numeri di genere e le osservazioni sotto soglia |
| `checklist.md` | La lista di controllo: parte A per uno screenshot, parte B per una tappa di meccaniche |

Le regole sono descrittive: dicono cosa fanno i giochi di successo, non cosa deve fare PATRÓN. Entrano nel gioco solo passando dal GDD, dopo il confronto della fase 5.
