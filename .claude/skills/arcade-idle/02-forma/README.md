# Forma: come appare il genere

Un file per campo, compilato nella fase 4 riunendo le osservazioni delle schede. Ogni file ha la stessa struttura: cosa si osserva gioco per gioco, cosa è comune, numeri (dove misurabili), eccezioni.

| Codice | File | Cosa si osserva |
| --- | --- | --- |
| F1 | `camera.md` | Angolo, rotazione, distanza, quanti oggetti stanno nello schermo, prospettiva o isometrica |
| F2 | `luce.md` | Quanta ombra, direzione, ambiente, contrasto tra facce in luce e in ombra |
| F3 | `colore.md` | Palette, saturazione, chiarezza dello sfondo, colori che indicano un ruolo |
| F4 | `modelli.md` | Livello di dettaglio, angoli tondi o vivi, scala degli oggetti rispetto al personaggio |
| F5 | `personaggi.md` | Forma, dimensione, come si distingue il giocatore, lavoratori e clienti |
| F6 | `ambienti.md` | Pavimenti, muri, disposizione delle stazioni, decorazioni, bordi del mondo |
| F7 | `oggetti-nel-mondo.md` | Pile, soldi a terra, tappetini di sblocco, fumetti, contatori, scritte sopra le stazioni |
| F8 | `interfaccia.md` | Cosa c'è sullo schermo fuori dal mondo: soldi, livello, pulsanti, dove stanno |
| F9 | `animazione.md` | Come si muovono personaggi e oggetti, risposte a ogni azione |
