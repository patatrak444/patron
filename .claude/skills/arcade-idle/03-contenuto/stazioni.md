# C2 Stazioni e filiera

Fonti: le righe "Contenuto" delle schede in `../01-catalogo/giochi/`, con gli indirizzi nelle note di `fonti/` e il quadro d'insieme in `rapporto-ricerca.md`. Sigle: PR Pizza Ready, BP Burger Please, MMM My Mini Mart, OR Outlets Rush, MPH My Perfect Hotel, PL Prison Life, FL Farm Land, MM Monkey Mart, MLU My Little Universe, WL Wasteland Life, DD Dreamdale.

## Gioco per gioco

| Gioco | Filiera | Passaggi |
| --- | --- | --- |
| [pizza-ready] | forno → bancone; confezioni → asporto; tavoli → spazzatura → cestino | 2 + ramo di ritorno |
| [burger-please] | piastra → cassa → drive-in; poi patatine, bibite, pizza | 2 |
| [my-mini-mart] | aiuola → banco; pollaio → banco uova; pomodori → frullatore → scaffale passata; cestino | 2–3, 9 postazioni nella prima mappa |
| [outlets-rush] | magazzino → scaffale → cassa; camerini | 2 |
| [my-perfect-hotel] | reception → camera → pulizia; più servizi (bagni, distributori, ristorante, parcheggio, piscina) | 2, molti in parallelo |
| [prison-life] | miniera → nastro → manette; lavanderia → divise; cucina; celle, bagni, visite | 2 |
| [farm-land] | campo → granaio → mercato | 1, senza trasformazione |
| [monkey-mart] | campo → scaffale → cassa; mais → animale → uova/latte; macchine che trasformano | 2–3 |
| [my-little-universe] | nodo → risorsa → edificio | 2 |
| [wasteland-life] | sabbia → rottami → riparazioni | 2 |
| [dreamdale] | nodo → mercato o costruzione | 1–2 |

## Cosa è comune

- **7/11** hanno almeno un passaggio di trasformazione (grezzo → prodotto): PR, BP, MMM, MM, MLU, WL, DD.
- **6/11** aggiungono un "lavoretto" del tema che non produce ma va fatto: spazzatura (PR, BP), cestino (MMM), camerini (OR), carta igienica e pulizie (MPH), bagni e celle (PL).
- Le filiere sono corte (2–3 passaggi); la profondità viene dall'aggiungere filiere parallele, non dall'allungarne una.
- [my-mini-mart] chiude un ciclo completo con le prime 3 postazioni (aiuola, cassa, banco) prima di introdurre un secondo prodotto; la cassa viene prima dello scaffale.
