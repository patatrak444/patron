# Contenuto: come funziona il genere

Compilata nella fase 3. Un file per campo, stessa struttura dei file di forma. `rapporto-ricerca.md` è il rapporto della ricerca che ha alimentato le schede; `fonti/` contiene le note con l'indirizzo di ogni dato. Quasi nessun numero di bilanciamento è pubblico: ogni file dice cosa resta da misurare sui video delle partite.

| Codice | File | Cosa si osserva |
| --- | --- | --- |
| C1 | `ciclo.md` | Il ciclo base, quanto dura un giro, cosa lo fa ripetere |
| C2 | `stazioni.md` | Che stazioni ci sono, quanti passaggi ha la filiera, come si collegano |
| C3 | `pila.md` | Capienza iniziale e massima, come si vede, cosa succede quando è piena |
| C4 | `sblocchi.md` | Come si sblocca, prezzi, distanza tra uno sblocco e l'altro, cosa si vede prima dello sblocco |
| C5 | `lavoratori.md` | Quando arriva il primo lavoratore, cosa fa, come si potenzia |
| C6 | `clienti.md` | Arrivi, file, pazienza, cosa comprano, come pagano |
| C7 | `economia.md` | Prezzi, crescita dei costi, guadagni offline |
| C8 | `progressione.md` | Livelli, nuove mappe o locali, ripartenze con moltiplicatori |
| C9 | `primi-minuti.md` | Cosa insegna il gioco nei primi 3 minuti e come |
| C10 | `temi.md` | Ambientazioni e come il tema si traduce in oggetti |
